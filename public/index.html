Welcome to G.U.R.U.

Your AI doctoral research supervisor — built for PhD law students. G.U.R.U. supervises your arguments, manages your references in OSCOLA, simulates your viva, and remembers everything you load into it.

You need a free Gemini API key to begin. No credit card required.

Get Your Free API Key

  1. Go to aistudio.google.com/apikey
  2. Sign in with your Google account
  3. Click Create API key
  4. Copy the key (starts with AIza)
  5. Paste it below

Tell G.U.R.U. about your PhD. The more specific you are, the more calibrated every response will be.

Key workflows
Literature review: Enable 🔍 SEARCH → ask by concept → Library auto-populates → use Cited By for depth → run Gap Analysis → push to Zotero
Citation management: Search builds Library automatically → Copy Fn to paste into Word footnotes → Export Refs .rtf for bibliography
Viva prep: Upload thesis to Vault → Examiner mode in Dialectic → full simulation in Viva tab
Supervisor report: Save argument maps to Journal → add reflections → Generate Supervisor Report → email
